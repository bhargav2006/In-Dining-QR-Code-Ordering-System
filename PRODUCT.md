# Restaurant QR Ordering System

## Product Overview

A restaurant dine-in QR ordering platform designed to connect customers, restaurant staff and administrators through a digital ordering experience.

The new frontend will be built independently while preserving compatibility with the existing backend.

## Main Objective

Create a polished, intuitive and reliable restaurant product with a distinctive visual identity.

The interface should feel like a professionally designed hospitality application rather than a generic admin-dashboard template.

## Intended User Groups

### Customers

Discover the restaurant menu, browse food categories, select items and use the supported QR-based dine-in ordering flow.

### Restaurant Staff

Manage and process customer orders using the operations supported by the existing backend.

### Administrators

Manage the restaurant's available configuration and operational features supported by the existing system.

## Functional Source of Truth

The existing backend and its verified API contracts determine which features are available.

Do not invent missing functionality.

Document unsupported or incomplete features separately.

## Technology Direction

Planned frontend: React + Vite.

Backend: Existing implementation preserved in backup/.

Database and API architecture: Preserve existing implementation.

## Design Principles

- Distinctive hospitality-oriented visual identity.
- Clear typography and visual hierarchy.
- Thoughtful use of whitespace.
- Strong mobile experience for customers.
- Efficient information presentation for staff.
- Intuitive navigation.
- Meaningful interaction feedback.
- Responsive and accessible layouts.
- Consistent Global Design System integration.
